# Roadmap การศึกษา Nonlinear Moving Horizon Estimation (NMHE)

## 1. ปูพื้นฐาน State Estimation และคณิตศาสตร์ (0 - 20)
เป้าหมายในระยะนี้คือการเข้าใจว่า "ทำไม" เราถึงต้องประมาณค่าสถานะ และทำความคุ้นเคยกับตัวประมาณค่าแบบดั้งเดิม

### 1.1 แนวคิดของ State Estimation
ทำความเข้าใจว่าสถานะ (States) คืออะไร ทำไมเซนเซอร์ที่มีอยู่ถึงไม่สามารถวัดค่าทุกอย่างในระบบได้โดยตรง หรือทำไมเซนเซอร์ถึงมี Noise
1) นิยามของสถานะ (States) และความสำคัญของการรู้ตัวแปรสถานะในการควบคุมระบบ
2) สาเหตุที่ต้องมีการประมาณค่า เช่น ข้อจำกัดทางฮาร์ดแวร์ งบประมาณ และสัญญาณรบกวน (Noise)
3) ความแตกต่างระหว่างภาพรวมการวัด (Measurement) แบบตรงๆ กับการประมาณ (Estimation) แบบอาศัยโมเดล

### 1.2 แบบจำลองทางคณิตศาสตร์ (System Dynamics)
ความแตกต่างระหว่างระบบ Linear และ Nonlinear
1) โครงสร้างสมการของระบบเชิงเส้น (Linear Systems) และข้อจำกัดในการใช้อธิบายระบบโลกความเป็นจริง
2) โครงสร้างสมการของระบบแบบไม่เป็นเชิงเส้น (Nonlinear Systems) และการแสดงพฤติกรรมที่ซับซ้อน เช่น แรงเสียดทาน อากาศพลศาสตร์
3) ความสำคัญของโมเดลทางคณิตศาสตร์ที่เป็นรากฐานของการทำ State Estimation ที่แม่นยำ

### 1.3 พื้นฐาน Kalman Filter (KF) และ Extended Kalman Filter (EKF)
ศึกษา EKF ในฐานะมาตรฐานอุตสาหกรรม เพื่อให้รู้ข้อจำกัดเมื่อเจอกับระบบที่ Nonlinear จัดๆ หรือมี Constraints
1) หลักการทำงานเบื้องต้นของ Kalman Filter ทางคณิตศาสตร์อย่างขั้นตอน Predict และ Update ควบคู่กัน
2) การประยุกต์ใช้ Extended Kalman Filter (EKF) ด้วยเทคนิค Linearization ผ่าน Jacobian Matrix
3) ข้อบกพร่องและข้อจำกัดของ EKF ต่อสภาวะระบบที่มีความเป็น Nonlinear สูงและเมื่อสถานะจำเป็นต้องจำกัดขอบเขตการทำงาน (Constraints)

### 1.4 พื้นฐาน Numerical Optimization
การหาค่าต่ำสุด/สูงสุด (Minimization/Maximization) เบื้องต้น ซึ่งเป็นหัวใจหลักของ NMHE
1) แนวคิดของการหาค่าเป้าหมาย (Objective Function) และการสร้างขอบเขตของปัญหา
2) ความเสี่ยงของการติดอยู่กับปัญหา Local Minima ที่พบได้บ่อยในระบบโจทย์ที่ไม่ใช่ Convex Optimization
3) โครงสร้างเบื้องต้นของการหาค่าหรือตัวแปรตัดสินใจ (Decision Variables) ที่ให้ค่าพารามิเตอร์คลาดเคลื่อนเกิดต่ำสุดอันเป็นแก่นหลักของ NMHE

## 2. เจาะลึกแนวคิดของ MHE และ NMHE (20 - 50)
ย้ายกระบวนทัศน์จากการกรองสัญญาณแบบ EKF มาเป็นการแก้โจทย์ Optimization ผ่านหน้าต่างข้อมูล

### 2.1 แนวคิด Sliding Window
การเลื่อนหน้าต่างรับข้อมูลการวัดในอดีต (Past Measurements) จำนวน $N$ สเต็ป
1) ความหมายของ Horizon Window จำนวน $N$ สเต็ปที่ต้องรับและเก็บข้อมูลจากการวัดเอาไว้ตลอดช่วงนี้
2) หลักการเลื่อนหน้าต่าง (Sliding Algorithm) ที่เอาเวลาล่าสุดเพิ่มเข้าไป และคัดทิ้งข้อมูลที่เก่าเกินหน้าต่างทิ้ง
3) ข้อดีของการจำกัดขนาดกรอบข้อมูล $N$ สเต็ปเมื่อเทียบกับการเก็บข้อมูลย้อนหลังทุกๆ ค่า (Full Information Estimation - FIE)

### 2.2 การตั้งค่า Cost Function
การทำความเข้าใจผลรวมของความคลาดเคลื่อน (Sum of squared errors) และการใช้เมทริกซ์น้ำหนัก (Weighting matrices)
1) โครงสร้างและแบบสมการเพื่อคำนวณหาผลรวมของกำลังสองความผิดพลาดของการวัดผลและสมการแบบจำลอง
2) การเซ็ตอัพกลุ่มค่า Measurement Noise Covariance Matrix ($R$) สำหรับถ่วงน้ำหนักระดับความน่าเชื่อถือที่ตัววัด (Sensors)
3) การเซ็ตอัพกลุ่มค่า Process Noise Covariance Matrix ($Q$) สำหรับถ่วงน้ำหนักระดับความน่าเชื่อถือที่ตัวระบบ (Model Dynamics)

### 2.3 Arrival Cost (Prior Information)
หัวข้อนี้สำคัญมาก เป็นวิธีสรุปข้อมูลทั้งหมดที่เกิดขึ้น "ก่อน" เข้าหน้าต่างข้อมูล $N$ สเต็ป เพื่อไม่ให้สูญเสียประวัติการทำงานของระบบ
1) สาเหตุที่ต้องมี Arrival cost หากไม่มีอาจเกิดปัญหาล้มเหลวของการเก็บประวัติสถานะตัวแปรหรือข้อมูลที่เกิดขึ้นก่อนหน้า
2) การนำเอาประวัติและสิ่งตกค้างก่อนเข้ามาคำนวณเพื่อเพิ่มเข้าสมการผ่านโหมด Penalty ให้เป็นตัวแทนของอดีต
3) ผลกระทบของการออกแบบเทอม Arrival Cost ต่อความถูกต้องและอัตราความรวดเร็วในการลู่เข้าของตัวแปร

### 2.4 การจัดการข้อจำกัด (Constraints Handling)
วิธีใส่เงื่อนไขทางฟิสิกส์ลงในตัวประมาณค่า เช่น อุณหภูมิห้ามติดลบ หรือวาล์วเปิดได้แค่ 0-100%
1) วิธีการสร้างสมการหรืออสมการกำหนดขอบเขตตัวแปร (Inequality Constraints Format) อย่างง่ายๆ
2) เข้าใจข้อจำกัดด้านกายภาพระบบ (State constraints) เช่น ข้อห้ามมอเตอร์ติดลบ ระดับของเหลวเกินกรอบ หรือมุมเลี้ยวที่มีจุดตายตัว
3) จุดเด่นของเครื่องมือระดับ MHE/NMHE ที่สามารถจัดการ Constraints เชิงปริมาณรักษากายภาพนี้ได้อย่างตรงไปตรงมาเมื่อเปรียบเทียบกับกลุ่ม KF และ EKF

## 3. คณิตศาสตร์เชิงลึกและอัลกอริทึม (50 - 70)
ระยะนี้จะเน้นการแปลงหลักการใน Phase 2 ให้เป็นสมการ Nonlinear Programming (NLP) เพื่อให้คอมพิวเตอร์แก้ปัญหาได้

### 3.1 การตั้งสมการ NLP สำหรับ NMHE
การกำหนดตัวแปรตัดสินใจ (Decision Variables) ซึ่งประกอบด้วย State เริ่มต้น และ สัญญาณรบกวนในอดีต
1) การนิยามกลุ่มตัวแปร (Decision Variables) สำหรับส่งต่อเข้าโปรแกรม และตระเตรียมตัวแปรเช่น สัญญาณรบกวนย้อนหลัง และสถานะตอนจุดเริ่มต้นหน้าต่าง
2) การเปลี่ยนโฉมและตั้งระบบสมการเชิงเส้น / ไม่เป็นเชิงเส้น (Equality constraints จาก Dynamics) ให้สอดรับโครงร่างย่อยแบบ Multiple Shooting
3) การจัดการความเรียบร้อยของหน้าต่างรวมสมการ NLP เพื่อรอป้อนลงสู่อัลกอริทึมแก้ปัญหา (Solver Preparation)

### 3.2 การคำนวณ Arrival Cost ขั้นสูง
การอัปเดต Arrival Cost ด้วยวิธี EKF Update หรือ UKF Update
1) วิธีการนำสมการความสัมพันธ์ (Covariance Update Matrix) ทาง EKF มาเสริมคำนวณจุดเชื่อมน้ำหนัก Arrival Cost
2) การปรับใช้ Unscented Kalman Filter (UKF) สอดแทรกให้สมจริงสำหรับการอัปเดต Arrival Cost ในระบบที่แสดงผล Nonlinear แบบรุนแรงกว่า
3) การวิเคราะห์ภาระการทำงานเทียบกับความแม่นยำในการเลือกวิธีการนำเอาข้อมูลน้ำหนักในอดีตโอนผ่านจุดตัดก่อน Window $N$

### 3.3 NLP Solvers
ทำความเข้าใจอัลกอริทึมเบื้องหลังที่ใช้แก้สมการ เช่น Sequential Quadratic Programming (SQP) หรือ Interior Point Method
1) กลไกของระบบคณิตศาสตร์แบบ Sequential Quadratic Programming (SQP) เพื่อแก้ปัญหายากโดยซอยโจทย์เป็นรอยอนุพันธ์ Quadratic Programming เบื้องต้นหลายๆ รอบ
2) กลไกของชุดแก้มูลอสมการแบบขอบโจทย์อย่าง Interior Point Method (IPM) และการใช้กำแพงสกัดโซน (Barrier Functions)
3) นัยสำคัญที่มีผลของคำสั่งต่อรูปแบบลักษณะความหนาแน่นแมทริกซ์การพึ่งพาระหว่างตัวแปร (Dense vs Sparse Matrices Effect)

### 3.4 Stability & Observability
การพิสูจน์และการตรวจสอบว่าตัวประมาณค่าของเราจะลู่เข้าหาความจริง (Convergence) หรือไม่
1) กรอบการวิเคราะห์เงื่อนไขด้านทฤษฎีของการสังเกตได้ (Observability Matrix Concept) บนแนวคิดสัดส่วนต่อ Nonlinear Systems
2) กลไกและที่มาในการรับประกันเส้นทางการลู่เข้าของข้อผิดพลาดว่าต้องอยู่ในช่วงปลอดภัย (Bounded Estimation Error Convergence Analysis)
3) แนวร่วมของค่าพลังงานฟังก์ชัน Lyapunov (Lyapunov Strategy Penalty Concept) เข้าไปหนุนความคงทนและสร้างหลักให้เสถียร

## 4. การลงมือเขียนโปรแกรม (Implementation & Tuning) (70 - 90)
นำสมคณิตศาสตร์มาแปลงเป็นโค้ด และทดสอบกับแบบจำลอง

### 4.1 เครื่องมือและไลบรารี
การใช้งานเฟรมเวิร์กที่ออกแบบมาเพื่อ Optimization โดยเฉพาะ (เช่น CasADi สำหรับ Python/MATLAB, หรือ ACADO Toolkit, do-mpc)
1) ขั้นตอนการเรียกใช้ CasADi Symbolic Level เพื่อดิฟหาความสัมพันธ์อนุพันธ์แบบไร้กังวลผ่านคอมพิวเตอร์ (Algorithmic Differentiation)
2) การนำการออกแบบ State Estimation มาส่องแสงผ่านคลาสแบบ OOP จากโปรแกรมและเฟรมเวิร์กอย่าง do-mpc แบบเร็วขึ้น
3) การขยายขีดความสามารถการคำนวณเวลาประมวลผลสูง (High Performance Requirement) สร้างผ่านการเสกรูป C++ Code Generation โดย ACADO Toolkit

### 4.2 การปรับจูนพารามิเตอร์ (Tuning)

#### 4.2.1 วิธีเลือกขนาด Horizon ($N$) ให้สมดุลระหว่างความแม่นยำและเวลาในการคำนวณ
1) การปรับ $N$ ขนาดย่อมหรือเล็กเกินเพื่อให้ประมวลผลได้ไว ซึ่งผลปรากฏเจอกับเสถียรภาพอ่อนแอต่อ Noise ผิดปกติ
2) การปรับ $N$ เป็นหน้าต่างทอดยาวเพื่อเพิ่มความแม่นและช่วยกรอง แต่ต้องแลกปัญหาจังหวะความหน่วงของการคำนวณรวม (Delay Processing)
3) แนวปฏิบัติการทดลองเพื่อจูนและจุดบรรจบที่ความต้องการประสิทธิภาพความจำคอมพิวเตอร์ในแนว Real-time

#### 4.2.2 การปรับเมทริกซ์ $Q$ (Process Noise) และ $R$ (Measurement Noise)
1) เทคนิคกรอบตีกรอบคำนวณตาราง Variance ของชุดอ่านเซนเซอร์นำเข้ามาใส่สูตรเมทริกซ์ $R$ อย่างถูกต้องตามสเปกชีส
2) เงื่อนปมในการจงใจหาจุดอ่อนและพิจารณาความไม่สมบูรณ์จุดต่อจุดมาถ่วงค่าสะท้อนเมทริกซ์ของสมการจำลอง $Q$ ให้รองรับสิ่งที่ไม่รู้นอกโมเดล
3) สัดส่วนอิทธิพลการให้น้ำหนักร่วมและการเปรียบเทียบเชิงวิศวกรหากสมการทั้ง $Q$ และ $R$ ให้ผลที่ขัดกันเกินจริงในกรณีเลวร้ายที่สุด

### 4.3 การจัดการ Computational Time
เทคนิค Real-time Iteration (RTI) เพื่อให้ NMHE คำนวณได้เร็วพอที่จะใช้ในงานจริง (Real-time application)
1) ข้อจำกัดด้านหน่วงปัญหาโครงสร้างเวลาของขอบเขตอัลกอริทึม Optimization (NLP delay limitations) หากแก้บรรลุก็คชวดรอบส่งสัญญาณ
2) เทคโนโลยีความสำเร็จในแวดวงที่ใช้แนว Real-time Iteration (RTI) เดินเพียงหน้า 1 QP step / Sample Data ต่อสเต็ปพร้อม Shift Initialization ให้เร็วพอกับรอบรันจริง (Control Loop Frequency)
3) การจัดการแบ่งภาระโพรเซสคอมพิวเตอร์จากรอบขนาน (Parallel concept) เป็นลักษณะสองฝั่งคือ Preparation Phase กับ Feedback Phase ให้รอกระชับวงที่สุด

## 5. การประยุกต์ใช้ในระดับสูงอุตสาหกรรม (90 - 100)
การนำ NMHE ไปเชื่อมต่อกับระบบควบคุมและการประยุกต์ใช้ในโลกความเป็นจริง

### 5.1 NMHE + NMPC Integration
การผนวกตัวประมาณค่า NMHE เข้ากับ Nonlinear Model Predictive Control (NMPC) เพื่อสร้างระบบควบคุมแบบปิด (Closed-loop) ที่สมบูรณ์
1) พัฒนาการวางท่อสัญญาณนำเอาวิถีแบบ Closed-Loop เต็มสูประหว่างบล็อคตัวรับ (NMHE Generator) ส่งให้บล็อกผู้ควบคุมเดินเครื่อง (NMPC Controller Optimizer)
2) ความยึดโยงระหว่างจุดชดเชยเวลาและการแยกตัวแปรเชิงหลักการ (Separation Principle Concept) ถึงประเด็นที่วิถีไม่ได้ตรงตัวเสมอสำหรับระบบระดับไม่เป็นเชิงเส้น (Nonlinear Control Rules)
3) ปัญหาและผลสะท้อนมุมมองที่ตามมาของหน่วงเวลาจากการสกัดค่าย้อนหลังและการสั่งค่าไปด้านหน้าจากรอบความถี่ที่หน่วงของคอมพิวเตอณ์ที่ไม่ได้อิสระ

### 5.2 Sensor Fusion
การใช้ NMHE ในการรวมข้อมูลจากเซนเซอร์หลายประเภท (เช่น การรวม GPS เข้ากับ IMU ในโดรน)
1) ปัญหาท้าทายและการผสานอัตรารับส่งที่แตกต่างหลายย่านความถี่พร้อมๆ กันจากส่วนรับ (Multi-rate Sensor Fusion Example: 10Hz GPS & 100Hz IMU System)
2) เทคนิคการพ่วงสมการโมเดลแบบจำลองเชิงฟิสิกของทิศทางรับเซทวัดลงร่วมเป็น Measurement Equations $y=h(x)$
3) กลไลเทคนิครัดกุมระดับพิเศษให้คัดแยกรอยผิดเพี้ยนแหลมคมออกรวดเร็ว (Outlier Sensor Rejection Capability) ผ่านฟังก์ชันเฉพาะทางทนทานแปลกปลอม (เช่น L1/Huber Norm Objective Formulation)

### 5.3 กรณีศึกษา (Case Studies)
การออกแบบ NMHE สำหรับหุ่นยนต์อัตโนมัติ (Autonomous vehicles), โดรน (UAV), หรือเครื่องปฏิกรณ์เคมีที่มีความซับซ้อน
1) โดรน (UAV System Setup): การวิเคราะห์โครงสร้าง NMHE ใช้ประเมินและทายค่าสภาะวะแรงลมแฝดรบกวนควบคู่แก้กลยุทธ์ IMU Drift อาการเซนเซอร์
2) หุ่นยนต์ยานยนต์ (Autonomous Vehicles Field): การคำนวณและประเมินเชิงตัวแปรเช่นปริมาณค่าเลื่อนไถลล้อยาง (Tire Slip Condition Variables) หรือจุดพลิกหน้าองศาในมุมที่ไม่สามารถอาศัยระบบเซนเซอร์ปกติ
3) กระบวนการเคมีหรือเครื่องปฏิกรณ์ (Chemical Process / Reactor Units): แนวทางวางโซลูชันของสภาพหน่วงจังหวะปฏิกริยาช้าหรือการเปลี่ยนแปลงสถานะที่ไม่สามารถวัดได้อย่างทันควันพร้อมความคลาดเคลื่อนระบบใหญ่
